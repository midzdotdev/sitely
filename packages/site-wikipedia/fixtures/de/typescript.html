TypeScript

TypeScript ist eine von Microsoft entwickelte freie und quelloffene Programmiersprache, die JavaScript um statische Typisierung mit optionalen Typannotationen erweitert.

Sie ist für die Entwicklung großer Anwendungen konzipiert und wird zu JavaScript transpiliert.
